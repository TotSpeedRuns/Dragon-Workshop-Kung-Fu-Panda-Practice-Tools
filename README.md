# Dragon Workshop — Kung Fu Panda Practice Tools

Developed and contributed by [TotSpeedRuns (Tot_sr)](https://github.com/TotSpeedRuns).

Download [Dragon Workshop v1.4.3](https://github.com/TotSpeedRuns/Dragon-Workshop-Kung-Fu-Panda-Practice-Tools/releases/tag/v1.4.3), extract the ZIP, and run **Dragon Workshop.exe**.

Includes PC practice v0.7.34, Wii practice v0.10.20, and autosplitter v0.12. PC builds use a separate practice folder and leave the original game untouched.

The PC JSON is bundled in the app; no standalone JSON download is needed. Use **Import patch update** for future revisions, or **Use bundled patch** to select this release’s default.

Triple jump trainer remains unavailable. Development gameplay changes still need confirmation.
